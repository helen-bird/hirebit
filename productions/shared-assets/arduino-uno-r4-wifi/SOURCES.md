# Arduino UNO R4 WiFi demo source record

This directory contains the common production inputs for the four formal Hypit demo Runs.

- Brand: Arduino
- Product: Arduino UNO R4 WiFi, SKU ABX00087
- Official store page: https://store.arduino.cc/products/uno-r4-wifi
